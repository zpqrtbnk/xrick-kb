  ---
  Analysis: GXUT275.PRG

  What it is: The GAMEX utility (v0.9), written by P. Putnik in 2011 as a
  companion tool for Rick Dangerous 2 on Atari ST. The filename breaks down as
  GXUT = GAmeX UTility.

  Primary purpose: Save and load game states (snapshots) for Rick Dangerous 2
  while it's running in RAM.

  ---
  How it works

  1. Hardware detection (startup)
  Reads the Atari TOS Cookie Jar for:
  - _CPU — CPU type (68000/010/020/030)
  - _MCH — machine type (ST, Mega STE, TT, Falcon)
  - _IDT — date/time format

  2. Game verification
  Scans RAM for the PPGX magic signature at a known offset — this is Rick
  Dangerous 2's internal engine marker (Platform Platform Game eXecutive or
  similar). It also checks for one of these GOS (Game Operating System) version
  strings in RAM: GOS 1.00, GOS 1.04, GOS 1.05, GOS 1.14, GOS 1.15 — making it
  compatible with multiple releases of the game.

  If the game isn't found → shows [No game in RAM!].

  3. Gamestate save/load
  Saves/loads snapshots to .FIC files. The file list checked at offsets
  0x205e–0x20a8:
  - D15R_NG1.FIC, D15R_F1.FIC, D15R_HH4.FIC, D15R_F4.FIC, D15R_5H.FIC,
  D15R_5F.FIC

  Two of these (D15R_5F.FIC, D15R_5H.FIC) are bundled pre-made saves in the
  RICKDA2 release.

  4. GEM/AES UI
  Uses Atari GEM dialogs with:
  - Enter notes / Show info / Cancel / Enter buttons
  - A "Gamex key" display field (a short identifier for the saved state)
  - Info view: machine type, TOS version, RAM layout (User bottom, TOS top,
  Total free)

  Error dialogs: Load error!, Save error!, No game in RAM!, Not gamestate file!,
  No enough RAM!, This snapshot requires file <filename.ext>
